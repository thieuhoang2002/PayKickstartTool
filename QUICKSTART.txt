🎯 GOAL: Tạo tài khoản PayKickstart hàng loạt + thu thập dữ liệu affiliate

📋 YÊU CẦU TRƯỚC KHOÁ (5 PHÚT SETUP)
================================================================================

CHỌN MỘT TRONG 2 CÁCH:

✅ CÁCH 1: Catch-All Email (Khuyến nghị - chạy 30-50 tài khoản/ngày)
   1. Mua domain ($1-2/năm) từ Porkbun.com
   2. Thêm vào Cloudflare (miễn phí)
   3. Bật Email Routing → Catch-all forward tới Gmail
   4. Tạo 1 Gmail App Password (16 ký tự)
   5. Chuẩn bị CSV:
      Email,MailPass,FirstName,LastName
      acc01@yourdomain.com,app_password_16_chars,John,Smith
      acc02@yourdomain.com,app_password_16_chars,Emma,Johnson

✅ CÁCH 2: Gmail Riêng (Simple - dùng khi test, 10-20 tài khoản/ngày)
   1. Có sẵn Gmail không cần mua domain
   2. Mỗi Gmail cần:
      - Bật 2-Step Verification
      - Tạo App Password (Settings → 2-Step → App Passwords)
   3. Chuẩn bị CSV:
      Email,MailPass,FirstName,LastName
      user01@gmail.com,app_pass_user01,John,Smith
      user02@gmail.com,app_pass_user02,Emma,Johnson

📌 CSV Template có sẵn trong: Data/Data.csv (edit + save)

================================================================================
🚀 QUICK START (10 PHÚT CHẠY)
================================================================================

▶ BƯỚC 1: CẤU HÌNH (Chỉ cần làm 1 lần)
   □ Mở tool
   □ Tab SETTINGS
   □ Nếu dùng CÁCH 1: Nhập Gmail catch-all → LƯU EMAIL
   □ Nếu dùng CÁCH 2: Bỏ qua bước này

▶ BƯỚC 2: TẠO TÀI KHOẢN
   □ Tab LOG
   □ CHỌN FILE → chọn Data/Data.csv
   □ Nhập số luồng (khuyến: 2 luồng)
   □ BẮT ĐẦU CHẠY → Chờ xong

   💡 Quan sát console log:
      - Mỗi dòng = 1 tài khoản được xử lý
      - Status: Thành công / Lỗi

▶ BƯỚC 3: KIỂM TRA KẾT QUẢ (Tạo tài khoản)
   □ Mở Results/ → KetQua_*.csv
   □ Xem cột Status: "Thành công" = OK, "Lỗi" = kiểm tra lại

▶ BƯỚC 4: CRAWL DỮ LIỆU (Tùy chọn - thu thập stats affiliate)
   □ Tab CRAWL DATA
   □ TẢI FILE → chọn KetQua_*.csv
   □ (TÙY) Tick checkbox chọn tài khoản hoặc crawl tất cả
   □ Nhập số luồng (khuyến: 3-5)
   □ CẬP NHẬT ACC ĐÃ CHỌN hoặc CẬP NHẬT TẤT CẢ
   □ Chờ progress bar 100% → Mở Results/Crawl/ xem JSON

================================================================================
🆘 TROUBLESHOOTING NHANH
================================================================================

❌ "Không nhận được email verify" (CÁCH 1)
   → Kiểm tra Cloudflare Email Routing đã bật chưa?
   → Gửi email test đến test@yourdomain.com để xác nhận

❌ "Không nhận được email verify" (CÁCH 2)
   → Kiểm tra Gmail App Password có đúng không?
   → Nếu sai, tạo lại App Password mới → update CSV

❌ Tool khởi động chậm hoặc bị đơ
   → Dùng 1 luồng thay vì 2-4 luồng
   → Tắt các ứng dụng khác đang chạy
   → Restart tool

❌ CAPTCHA xuất hiện liên tục
   → Chạy quá nhanh - giảm số luồng xuống 1
   → Đợi 30 phút rồi chạy tiếp batch khác

================================================================================
💡 TIPS CHẠY HIỆU QUẢ
================================================================================

✅ Nên làm:
   • Test với 5-10 tài khoản trước khi chạy 100+
   • Backup file Results/ thường xuyên
   • Chạy 20-30 tài khoản mỗi lần, nghỉ 30 phút rồi tiếp
   • Dùng proxy chất lượng khi scale 50+ (mua từ IPRoyal/Bright Data)
   • Monitor console log realtime để phát hiện lỗi sớm

❌ Không nên:
   • Chạy 100+ tài khoản không proxy
   • Set luồng = 10 lần chạy đầu tiên
   • Dùng domain vừa mua chưa warm-up (chờ 24h)
   • Shared tool + email/domain với người khác (security risk)
